# Website pages

Sources: PROJECT_SPEC AC-12.2, AC-12.3, AC-12.4, AC-6.5; ARCHITECTURE D6; brand tokens in this repo.

## Stack

Static HTML/CSS under `website/site/`, published as a GitHub Pages project site. No Next.js/shadcn in this path. Mirror `tokens/brand.css` into `website/site/brand.css` when tokens change. Catalog HTML is generated by `website/scripts/generate-site.mjs` from committed `website/data/*.json`.

## Page inventory

| Page | Path | Job |
|---|---|---|
| Product | `index.html` | Brand-first product overview; roles; screenshot policy |
| Workflow | `workflow.html` | Matchday journey steps; control vs media |
| Downloads | `downloads.html` | Source repo links; honest release status |
| Docs | `docs.html` | Entry stub to `OpenMatchday/docs` |
| Capabilities | `capabilities.html` | Generated verified/partial/unverified matrix |
| Sports | `sports.html` | Generated available + planned catalog (AC-6.5) |
| Themes | `themes.html` | Generated declarative theme catalog |
| Assets | `assets.html` | Default package courts, formations, scoreboard schemas |
| Registry | `registry.html` | Searchable fictional registry samples (not live matches) |
| Contribute | `contribute.html` | Google sign-in + registry submission wizard (calls community API) |
| Status | `status.html` | Submission status lookup (queued / PR opened / changes requested / merged / rejected) |
| Privacy | `privacy.html` | Local-first, registry, contact stub |
| Takedown | `takedown.html` | Public takedown stub; no Git-history erasure promise |

Community API base URL lives in `website/data/site-meta.v0.json` (`community_api_base`). No community secrets in the static site.

## SEO and a11y (AC-12.4)

- Skip link to `#main` on every page.
- Titles, descriptions, canonical, Open Graph, JSON-LD WebPage, `sitemap.xml`, `robots.txt`.
- Public pages `index,follow`; private pages use `noindex` when introduced.
- Responsive from 320 px; performance budget in `website/data/perf-budget.v0.json` checked in CI.
- WCAG 2.2 AA target: semantic landmarks, focus-visible, form labels, no zoom disable.

## Rules

- Brand name is a hero-level signal on marketing pages.
- Real screenshots only; never fabricate device-frame UI shots (AC-12.3).
- No unmeasured latency/bitrate numbers.
- Planned sports never render as available playable shells.
- Tally red is not decorative chrome on the marketing site.
- Honor `prefers-reduced-motion`; no `backdrop-filter: blur`.
